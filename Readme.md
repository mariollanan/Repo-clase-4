## inicializar un repositorio 

git init

## añadir Seguimiento de cambios

git add .

## crear Versiones 

git commit -m 'comentarios/ descripcion de la version '

## revisar status
git status 

## revisar Historial de commits

git log 

## añadir origen remoto con git 
git remote add origin <url>

## Corroborar el origen remoto 

git remote -v 

## cambiar el origen remoto

git remote set-url origin <url>

## subir el codigo al repositorio en github

git push -u origin main
